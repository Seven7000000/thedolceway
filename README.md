# The Dolce Way

Personal tech blog covering AI tools, software development, and building in public.

**Live site:** [thedolceway.com](https://thedolceway.com)

## Tech Stack

- **Framework:** [Astro](https://astro.build/) — static site generation with content collections
- **Styling:** Tailwind CSS
- **Hosting:** Cloudflare Pages
- **CMS:** Markdown-based content with frontmatter

## Features

- Fast, SEO-optimized static pages
- Blog posts on AI, development workflows, and project updates
- RSS feed support
- Responsive design

## Development

```sh
npm install      # Install dependencies
npm run dev      # Start local dev server at localhost:4321
npm run build    # Build production site to ./dist/
```
